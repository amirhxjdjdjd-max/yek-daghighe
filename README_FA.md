# یک دقیقه جای من باش

یک وب‌سایت تعاملی فارسی و راست‌چین برای تجربه‌ی موقعیت‌های اجتماعی از زاویه‌ی دید افراد مختلف. این نسخه برای ارائه‌ی دانشگاهی و انتشار رایگان روی GitHub Pages آماده شده است.

## ویژگی‌ها

- کاملاً استاتیک؛ بدون سرور، پایگاه داده یا API هوش مصنوعی
- واکنش‌گرا و مناسب موبایل و دسکتاپ
- پنج داستان تعاملی، هرکدام با سه موقعیت و سه انتخاب
- بازخورد فوری برای هر انتخاب و جمع‌بندی در پایان داستان
- بدون ثبت‌نام و بدون ذخیره یا ارسال انتخاب‌های کاربران
- بدون نیاز به نصب کتابخانه یا ابزار ساخت (build)

## اجرای محلی

کافی است فایل `index.html` را با مرورگر باز کنید. برای تجربه‌ی بهتر می‌توانید پوشه را با افزونه‌ی Live Server در VS Code اجرا کنید؛ اما این کار ضروری نیست.

## انتشار رایگان با GitHub Pages

1. در GitHub یک مخزن جدید (Repository) بسازید؛ مثلاً با نام `yek-daghighe`.
2. فایل‌های `index.html`، `styles.css`، `app.js` و `README_FA.md` را در ریشه‌ی مخزن بارگذاری کنید.
3. وارد بخش **Settings → Pages** مخزن شوید.
4. در قسمت **Build and deployment**، گزینه‌ی **Deploy from a branch** را انتخاب کنید.
5. شاخه‌ی `main` و پوشه‌ی `/(root)` را انتخاب و روی **Save** بزنید.
6. پس از انتشار، GitHub آدرس سایت را در همان صفحه‌ی Pages نشان می‌دهد. معمولاً آدرس شبیه این است:
   `https://YOUR-USERNAME.github.io/yek-daghighe/`

برای این روش خرید دامنه لازم نیست. آدرس رایگان GitHub Pages برای ارائه و اسکن QR Code مناسب است. اگر بعدها دامنه‌ی اختصاصی خریدید، می‌توانید آن را از تنظیمات Pages متصل کنید.

## تغییر و اضافه کردن داستان

اطلاعات داستان‌ها در ابتدای فایل `app.js` و داخل آرایه‌ی `stories` قرار دارد. هر داستان شامل این بخش‌هاست:

- `id`: شناسه‌ی یکتا و انگلیسی
- `title` و `short`: عنوان و توضیح کوتاه
- `intro`: معرفی داستان
- `icon` و `symbol`: نماد نمایشی
- `color` و `tint`: رنگ کارت و تصویر داستان
- `scenes`: موقعیت‌ها، پرسش‌ها و انتخاب‌ها
- `endings`: جمع‌بندی مسیرهای مختلف
- `insight`: نکته‌ی پایانی برای فکر کردن

برای افزودن یک داستان، یک شیء دیگر با همین ساختار به آرایه اضافه کنید. ساختار هر `scene` و هر `choice` را از نمونه‌های موجود کپی کنید.

## نکته‌ی محتوایی و حریم خصوصی

این پروژه یک تجربه‌ی داستانی و آموزشی است و آزمون شخصیت، ابزار تشخیص یا ارزیابی روان‌شناختی نیست. موقعیت‌ها داستانی و برای گفت‌وگو طراحی شده‌اند. در نسخه‌ی فعلی هیچ داده‌ای از انتخاب کاربران به سرور فرستاده یا در جایی ذخیره نمی‌شود.

## نکته درباره فونت

فونت Vazirmatn از Google Fonts بارگذاری می‌شود. اگر اینترنت در دسترس نباشد، سایت به فونت‌های جایگزین سیستم (مانند Tahoma) برمی‌گردد. در صورت نیاز به نسخه‌ی کاملاً آفلاین می‌توانید فونت را به‌صورت محلی به پروژه اضافه کنید.
